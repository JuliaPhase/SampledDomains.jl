## Overview

> **Note:** this overview is a temporary README generated by AI (Claude) and has not yet been reviewed by the author.

SampledDomains attaches physical coordinates to array elements, so that an array entry a[j,i] can be interpreted as f(x_i, y_j) for some function f (first index runs along y, second along x, as for images). A domain is a lazy array of the points (x, y) of the samples. The package provides Cartesian domains, centred domains, dual (Fourier) domains and affine (rotated, reflected or shifted) domains, and is used as a base for other Phase.jl packages.
