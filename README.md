## Overview

> **Note:** this overview is a temporary README generated by AI (Claude) and has not yet been reviewed by the author.

SampledDomains attaches physical coordinates to array elements, so that an array entry a[j,i] can be interpreted as f(x_i, y_j) for some function f (first index runs along y, second along x, as for images). It provides Cartesian domain types, centred domains and dual (Fourier) domains, and is used as a base for other Phase.jl packages.
